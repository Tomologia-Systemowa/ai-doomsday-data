# Skill `ai-doomsday` – kopia referencyjna

Ten katalog zawiera rozpakowaną kopię skilla `ai-doomsday` (plik `ai-doomsday.skill`):
instrukcję (`ai-doomsday/SKILL.md`), opis sygnałów i publikacji (`references/`) oraz skrypty
liczące wynik, walidujące i zapisujące JSON (`scripts/`).

To **kopia referencyjna metodologii** – pozwala przeczytać, jak powstaje skala 0–1000
i pliki w `data/`. Rutyna publikująca dane **nie korzysta z tego katalogu**, tylko
z zainstalowanej wersji skilla, więc zmiany tutaj nie wpływają na raporty. Po aktualizacji
skilla warto podmienić tę kopię, żeby była zgodna z wersją zainstalowaną.
